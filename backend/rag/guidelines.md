# Audio-description methodology for sequential art

Adapted from established audio-description practice (used for film/TV
description and extended here to comics/manga panels) — grounds the vision
model's output in real conventions rather than free-form guessing.

1. Describe only what is visually essential to following the story — not
   every visual detail in the panel.
2. State objective, observable facts before subjective interpretation (e.g.
   "her fists are clenched" before "she is furious").
3. Describe action and events before physical appearance, unless
   appearance is itself story-relevant in this panel.
4. Never describe what dialogue or on-page text already conveys — audio
   description fills gaps, it does not repeat.
5. Identify who is speaking whenever it would not otherwise be clear from
   voice alone (e.g. an unnamed figure's first appearance).
6. Use present tense, as if narrating the moment as it happens.
7. Signal scene, time, or location changes explicitly the first time they
   occur in a panel.
8. Avoid editorializing language ("beautifully," "sadly," "tragically")
   unless it reflects the artist's own clearly stated intent, not the
   describer's opinion.
9. Prioritize plot- and emotion-critical visual information over
   exhaustive inventory of background elements.
10. Keep descriptions concise enough to fit the pacing of the panel — a
    single splash-page panel can carry more description than a rapid
    action sequence.
11. When a panel's visual meaning is ambiguous, hedge honestly ("possible
    flashback," "unclear if same character") rather than asserting false
    precision.
12. Preserve the sequence's emotional beat (tension, relief, humor) through
    word choice and pacing cues, not just literal content.
